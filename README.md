# Personal Expense & Budget Manager

A Java-based web application for managing personal income, expenses, budgets, savings goals, and recurring expenses.

## Features

* Income and expense management
* Expense categories
* Monthly budget tracking
* Transaction history and filtering
* Monthly expense summary
* Savings goal tracking
* Recurring expense tracking
* Financial dashboard

## Technologies

* Java 23
* Servlets & JSP
* JDBC
* MySQL
* HTML5 & CSS3
* Maven
* Apache Tomcat

## Architecture

**Browser → JSP/HTML → Servlets → DAO/JDBC → MySQL**

## How to Run

1. Create the `expense_manager` database in MySQL.
2. Update your MySQL credentials in `DBConnection.java`.
3. Build the project using Maven.
4. Deploy the WAR file on Apache Tomcat.
5. Open the application in your browser.
